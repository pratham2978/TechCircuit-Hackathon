# ML Data Directory

This directory stores datasets for local training, validation, and evaluation:

- `brand_tone_seed.csv`: Primary seed dataset (500 curated examples, 100 per class).
- `splits/`: Train (70%), Validation (15%), and Test (15%) splits generated by `ml/scripts/make_splits.py`.
- `benchmarks/`: Fixed hold-out test benchmark for regression testing.

### Rules & Integrity:
1. Every row must include an `is_synthetic` boolean flag.
2. No sensitive company data or unverified external datasets should be committed.
